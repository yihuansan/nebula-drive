# NebulaDrive 文件管理页面布局大更新计划

> 目标：以 Nextcloud / Google Drive / Dropbox / OneDrive / Seafile / FileZilla 为参照，
> 统一 7 主题 × 4 布局的 DOM 骨架，消除"排版乱"，实现一套骨架 + 主题变量驱动外观。
> 原则：**DOM 结构全主题一致，主题只改 CSS 变量；不新增后端 API；不改业务逻辑。**

## 3. 布局改造方案

### 3.1 目标骨架（全主题同一 DOM）

```
┌──────────────────────────────────────────────────────────┐
│ Header(60px)：[☰ 仅移动端] [页面标题]        [主题/用户]   │
├──────────────┬───────────────────────────────────────────┤
│ 侧栏 240px   │ 行1 面包屑：…/父级/当前（flex:1，溢出省略）  │
│ - 我的文件    ├───────────────────────────────────────────┤
│ - 最近        │ 行2 控件：[搜索 220~360px] [⋯更多] [网格|  │
│ - 共享        │           列表|照片] [排序▾] [上传][新建]   │
│ - 回收站      ├───────────────────────────────────────────┤
│              │ 统计条(1行)：配额 ███ 62% | 总量 | 文件数 | 本周│
│ [存储进度条]  ├───────────────────────────────────────────┤
│              │ 文件区：grid / list / photo（三视图共用容器） │
└──────────────┘
```

### 3.2 关键决策

1. **两行工具栏**（Google Drive）：行 1 面包屑全宽 + 溢出"…/父/当前"；行 2 控件右对齐，窄屏时搜索优先保宽、操作按钮收进"⋯"。
2. **侧栏升级**（Nextcloud/OneDrive）：新增 最近/共享/回收站 导航项（路由已存在则直链，否则占位 disabled）；底部存储进度条复用 `usageTotal/quota`（script 已有，无需新 API）。
3. **统计条**：全主题 1 行紧凑条（配额/总量/文件数/本周趋势）；仅 dashboard 主题保留大 4 卡版（复用同一数据源）。
4. **网格**：`repeat(auto-fill, minmax(clamp(150px,18vw,220px),1fr))`；把 glass.css 里 `!important` 的 gap/padding/radius 改为每主题 CSS 变量（`--card-gap/--card-pad/--card-radius`），删除 `!important`。
5. **Bento**：≥1200px 4 列；≤1199px 3 列；≤767px 2 列且 featured/medium 通栏。
6. **Command**：显示最小工具栏（存储切换 + 排序 + 视图切换），⌘K 面板不变。
7. **移动端 <768px**：侧栏 → 离屏抽屉（☰ 打开，Esc/点外关闭）；搜索 → 全屏搜索覆盖层；操作 → "⋯" 更多菜单（ElPopover）；网格 2 列；列表视图 → 卡片行。
8. **组件化**（可维护性）：Files.vue 模板/CSS 拆为 `FilesToolbar.vue`、`FilesSidebar.vue`、`StatsStrip.vue`、`FileGrid.vue`、`FileList.vue`，script 逻辑留在 Files.vue 通过 props/emits 通信。

## 5. 验收标准（QA 逐项打勾）

**桌面 ≥1200px**
- [ ] 工具栏两行：行 1 面包屑（深层显示"…/父/当前"，不撑爆）；行 2 控件右对齐，无意外折行
- [ ] 侧栏 240px：我的文件/最近/共享/回收站 可点击；底部存储进度条数值 = usageTotal/quota
- [ ] 统计条 1 行：配额/总量/文件数/本周趋势 可见
- [ ] 网格：auto-fill 无水平滚动，gap/radius 各主题一致（无 `!important`）
- [ ] 列表：名称/大小/时间 表头点击排序 + 方向箭头
- [ ] 照片视图：仅图片，网格无混入文件卡
- [ ] Command 主题：最小工具栏（存储/排序/视图）+ ⌘K 面板功能不变
- [ ] Bento：4 列 + featured 2×2；≤1199px 3 列；≤767px 2 列且 featured/medium 通栏

**移动端 <768px**
- [ ] 侧栏 → 抽屉（☰ 打开、Esc/点外关闭、不遮挡内容时 body 滚动锁定）
- [ ] 搜索 → 全屏覆盖层；"⋯" 更多菜单内可触达全部操作（上传/新建/多选/排序）
- [ ] 网格 2 列无溢出；全站无水平滚动（document.scrollingElement.scrollWidth ≤ window.innerWidth）

**全 7 主题**
- [ ] DOM 结构一致，差异仅 CSS 变量（color/blur/radius/font）
- [ ] glass.css 中 grid gap/padding/radius 无 `!important`
- [ ] 文本对比度 ≥4.5:1；移动端可点击元素 ≥44px 热区

**功能回归（不得破坏）**
- [ ] 上传/下载/重命名/移动/复制/共享/协作共享/标签/右键菜单/预览/解压 全部可用
- [ ] 视图切换状态持久化（localStorage）
- [ ] 三视图切换无闪烁，骨架屏正常
